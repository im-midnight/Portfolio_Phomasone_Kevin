Jeu de Plateforme
Mario Maker

Un jeu de plateforme inspiré de Super Mario Maker, développé en Python avec Pygame en première année. Éditeur de niveaux complet, deux types d'ennemis avec IA, système d'objets, musique originale composée par moi, et support manette Xbox 360.

Python Pygame Projet de Groupe NSI · 1ère Année Terminé
Voir sur GitHub
Fonctionnalités
Éditeur de Niveaux

Grille sur 10 feuilles, placement de blocs, ennemis, objets et portails. Sauvegarde et chargement en JSON. Interface avec sélecteur d'éléments intégré.

Physique du Joueur

Déplacements, saut, course, grimpe d'échelle. Effets spéciaux : rebond sur slime, glissade sur glace, boules de feu avec cooldown.

Ennemis avec IA

Zombie (attaque au contact dans un rayon de 8 blocs) et Cyclope (gestion de distance, tir de boule de feu toutes les 5s). Chacun possède 3 PV.

Blocs Variés

Briques, piques, blocs fantômes, slime, glace, échelles, boîtes mystères avec loot, portails de fin. Chaque bloc a un comportement unique.

Musique Originale

Bande sonore intégralement composée par moi, jouée en jeu via Pygame.

Support Manette

Compatible Xbox 360 en plus du clavier. Détection plug-and-play à n'importe quel moment de la partie.

Extrait de Code
player.py — Physique & collisions
class Player:
    def __init__(self, x, y):
        self.x, self.y = x, y
        self.vx, self.vy = 0, 0
        self.on_ground = False
        self.pv = 3          # points de vie
        self.coins = 0

    def update(self, blocs, items, ennemis):
        # Appliquer la gravité
        self.vy += 0.5
        self.x += self.vx
        self.y += self.vy
        self.on_ground = False

        for bloc in blocs:
            if bloc.est_solide() and self.collision(bloc):
                if self.vy > 0:           # tombe sur le bloc
                    self.y = bloc.y - self.hauteur
                    self.vy = 0
                    self.on_ground = True

    def sauter(self):
        if self.on_ground:
            self.vy = -12   # impulsion vers le haut
