Projet Golang · BUT Informatique

Système de
Particules

Simulation 2D d'un système de particules développé en Go avec la bibliothèque Ebitengine. Le projet gère la gravité, les collisions, les formes de générateur, les variations de couleur et bien plus encore.

Golang Ebitengine 2D Simulation SAE BUT INFO
Voir sur GitHub

Fonctionnalités

Gravité

Système de gravité configurable dynamiquement. Activez, désactivez et ajustez la valeur en temps réel depuis l'interface.

Collisions

Détection et résolution physique des collisions entre particules via les fonctions Collision() et Gerer_Collision().

Forme du générateur

Choisissez la forme d'émission des particules : point fixe ou cercle avec rayon ajustable.

Variation de couleur

Les particules changent de couleur dynamiquement au cours de leur cycle de vie pour des effets visuels riches.

Générateur mobile

Activez le mode souris pour que les particules apparaissent à la position du curseur en temps réel.

Spawn Rate

Contrôlez le taux d'émission des particules et activez le mode Random Spawn pour une dispersion aléatoire.

Contrôles

Navigation

Naviguer dans le menu W / S
Augmenter la valeur Enter
Diminuer la valeur Shift
Spawn à la souris Souris

Paramètres dynamiques

Activer / désactiver gravité Gravity
Activer / désactiver collisions Collision
Forme circulaire Circle
Spawn aléatoire Random

Structure du projet

src/ — arborescence 
src/
├── assets/          # Gestion des ressources (images)
├── circle/          # Formation circulaire des particules
├── config/          # Configuration du projet
├── couleur/         # Gestion des couleurs
├── gravity/         # Système de gravité
├── particle/        # Création des particules
├── particles/       # Système de particules et collisions
├── texte/           # Affichage de texte
├── draw.go          # Rendu graphique
├── game.go          # Logique du jeu
├── main.go          # Point d'entrée
└── update.go        # Mise à jour de l'état
